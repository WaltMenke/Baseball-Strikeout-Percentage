# Baseball-Strikeout-Percentage

This project predicts next season strikeout rate (K%) for MLB pitchers using Stuff+ and prior season performance. A key early finding was that raw K% is unreliable for pitchers with very few batters faced (e.g., a 100% strikeout percentage from a single batter). This project addresses that directly by modeling strikeouts as a binomial outcome, letting the sample size itself inform how much to trust each observation. The core model is a binomial GLM trained on year-over-year transitions (2021–2024) and evaluated out-of-sample against actual 2025 results. It beats a persistence baseline (last season's strikeout percentage) by roughly 13% and a league-average baseline by roughly 19% on total-batters-faced weighted MAE. An XGBoost comparison is also included to test whether a more flexible model captures additional signal beyond the interpretable GLM. See the notebook for full methodology, diagnostics, and results.
